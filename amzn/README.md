# Amazon.com, Inc. (AMZN)

## Company Overview
Amazon.com, Inc. is the world's largest e-commerce and cloud computing company. The company operates through multiple segments including online stores, physical retail, subscription services, and Amazon Web Services (AWS), which provides cloud infrastructure and services to businesses globally.
