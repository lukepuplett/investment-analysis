## Discounted Cash Flow (DCF) Analysis — Revisited

### What Changed Since January
The January DCF used a base case of $18.5B 2026E revenue and a 2028E target of $24B, derived from the pre-upgrade Springboard numbers. Management's May 2026 Investor Day and this Q2 print reiterate a **more aggressive** target: $20B annualized run-rate by end-2026 (a quarter early), $30B by end-2028, $40B by end-2030. Directionally this argues for a **higher** DCF fair value than January's $115-130 base case, all else equal — but the January DCF was already using a discount rate and terminal margin assumption that didn't fully capture how much faster the "high-confidence" targets have moved. A full DCF rebuild is warranted for the next full analysis cycle; for this update we treat the January DCF as a floor reference and flag the direction of revision.

### Directional DCF Update (not a full rebuild)
| Input | January Base Case | Implied Update (Q2 2026) | Direction |
|-------|--------------------|-----------------------------|-----------|
| 2026E Revenue | $18.5B | Tracking to ~$20B run-rate by year-end (a quarter early) | Higher |
| 2028E Revenue | $24.0B | Management's own target now $30B by end-2028 | Materially higher |
| Terminal Growth | 3.0% | Unchanged assumption | Same |
| WACC | 7.5% | No change to risk-free/beta assumptions this cycle | Same |
| Operating Margin (blended) | 19.5-20.8% | Q2 core operating margin already 20.9%, ahead of the 2026E path | Higher |

**Implication:** If the January DCF produced a base-case fair value of $115-130 using the *lower* growth trajectory, and the actual trajectory is now tracking to the higher, upgraded Springboard targets, the "true" DCF fair value is likely **above** $115-130 — plausibly in the $130-160 range once the higher 2028/2030 revenue targets are properly modeled. **This is a directional estimate, not a rebuilt DCF — flag for the next analysis cycle to formalize.**

At the current price of $124, the stock is trading:
- **Below** the January DCF base case midpoint if using the upgraded targets
- **Within** the January DCF base-case range ($115-130) if being conservative and not yet crediting the upgraded targets

Either read supports the same conclusion: **the post-earnings price is not obviously overvalued on a DCF basis**, in sharp contrast to January's finding that $167 was already 22-37% above consensus fair value.

## Key Risks to This Valuation Read

1. **No full DCF rebuild performed this cycle** — the "likely higher fair value" conclusion is directional reasoning, not a recalculated model. Treat with appropriate skepticism until formalized.
2. **Peer multiples not refreshed** — comparison table uses January reference points for peers; only GLW's own multiples are current.
3. **The market's own signal**: three trading sessions ago the market was willing to pay 80x forward earnings; two days later, 39x. This is a reminder that sentiment/momentum can dominate DCF logic for extended periods in both directions — don't assume the current multiple is a floor.
4. **Q3 delivery is the near-term catalyst.** If Corning merely hits the $4.9-5.0B / $0.85-0.89 guide without signalling reacceleration, the multiple compression seen this week may continue rather than stabilize.

## Conclusion

The July 2026 selloff moved Corning from a stretched, momentum-priced valuation (~80x forward P/E, implied market cap north of $219B at quarter-end) to a more defensible level (~39x forward P/E, $106.6B market cap) that sits close to or below this repo's last DCF-derived fair value estimate. Given management has since *raised*, not lowered, its long-term growth targets (the May 2026 Springboard upgrade to $30B/$40B run-rates by 2028/2030 remains in place), the fundamental case for the stock has not weakened — only the price paid for it has become more reasonable. The key open item for the next valuation cycle is a full DCF rebuild reflecting the upgraded targets, which would likely support a fair value meaningfully above the stale January $115-130 range.
